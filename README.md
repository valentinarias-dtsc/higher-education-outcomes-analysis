# Higher Education Outcomes Analysis

Data analysis project focused on understanding academic completion patterns in higher education programs and identifying factors associated with student performance.

## Project goal

This project analyzes enrollment, progression, and completion patterns across academic programs to identify:

- completion rate differences between programs
- impact of course modality
- relationship between student status and graduation outcomes
- actionable opportunities for institutional improvement

## Key insights

- Significant variation exists in completion rates across programs.
- Modality and student condition are strongly associated with academic outcomes.
- Some low-performing programs appear to be affected more by delayed progression than by abandonment.
- Targeted interventions may improve completion efficiency.

## Data availability

The original dataset is **not included** in this repository.

It was accessed under a confidentiality agreement and cannot be publicly redistributed.

To preserve reproducibility:

- all processing logic is included
- cleaning functions are documented
- synthetic sample data may be provided for demonstration

## Methodology

Main steps:

4. metric construction
